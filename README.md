# Ekakshar Shreyas - Portfolio

Static site (HTML, CSS, JavaScript). No build step.

Folder layout (names are case-sensitive on GitHub Pages):

    index.html
    Ekakshar_resume.pdf      <- same folder as index.html
    images/ekakshar.jpeg     <- your photo
    css/  js/

Deploy: push to GitHub, then Settings -> Pages -> branch `main`, folder `/ (root)`.
index.html must be at the top level of the repo, not inside another folder.
